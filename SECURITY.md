# Security policy

## Reporting a vulnerability

Please report a suspected vulnerability by opening a **private security advisory** for this repository on GitHub. Do not disclose an unpatched vulnerability in a public issue.

Include the affected file or feature, the steps needed to reproduce the issue, and its likely impact. Do not include real access tokens or other secrets in the report.

## Scope

Reports in scope include vulnerabilities in CodePusher's token handling, message validation and sender checks, repository path construction, handling of coding-site content, permissions, and GitHub API requests.

The following are out of scope:

- Vulnerabilities in GitHub, LeetCode, Codeforces, Chrome, or other software that CodePusher does not control.
- Attacks that require someone to already have access to the user's unlocked device or local browser profile.
- Rate limits, challenge pages, or service outages on GitHub, LeetCode, or Codeforces.
- Requests for features or reports that do not describe a security vulnerability.
